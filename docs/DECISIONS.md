# DECISIONS

- D001 2026-10-16：仓库为空，首阶段采用已有运行环境中的 Python/FastAPI + SQLite，避免依赖外部基础设施。单节点本地持久卷，BEGIN IMMEDIATE 串行化写事务；高吞吐多节点 PostgreSQL 迁移为后续任务，不能将本阶段称为大规模生产方案。
- D002：总控独占 schema/迁移/API 契约，子任务仅写各自目录，集成前核对契约。阶段一见 CONTRACT.md。
- D003：收货/质检记录与可售库位库存分离；上架才增加可售实物库存。预占/拣货/复核/打包不重复扣实物，交接出库才扣一次。退货收货且质检上架后增加库存。
- D004：Bearer token 仅保存 SHA-256 摘要，服务端租户、货主和仓库权限。变更必须有幂等键；不同请求复用键报错；按货主/店铺唯一外部订单号。
- D005：取消只支持未拣货订单；拣货后取消需实体归位流程，后续实现；已出库只能经退货流程。
- D006：中葡界面、BRL 整分记账；ERP provider 全部待接入，内部 API 与服务商 API/卖家自用 API 明确区分。
- D007：`on_hand` 表示合格已上架库位库存；待检、合格未上架与残次实物按单据状态另记，`stock_summary.physical_total` 汇总实际保管总量。退货通知不计入实物；残次未做报废前仍在保管。UI 展示质量分区，不能把物理总量当作可售。
- D008：本环境 Docker build 网络无法解析依赖源；获授权下载固定版本 wheels 到忽略目录 wheelhouse，Dockerfile 支持 WMS_OFFLINE=1 离线安装。基础镜像固定已拉取 digest；不修改宿主 DNS/代理/网络。
- D009：首阶段用 30 天可撤销 API 凭证登录，CLI 在本机受控边界签发。密码、MFA/SSO、审批、在线凭证轮换、CLI管理操作完整审计尚未实现，是正式生产启用前的安全验收项；不能宣称完整身份平台。
- D010：未知浏览器响应锁定原提交，保留原请求/幂等键后重试；业务成功与 UI 数据刷新失败分开提示。刷新页面会丢失内存状态，跨重载的持久客户端待提交队列尚未实现。

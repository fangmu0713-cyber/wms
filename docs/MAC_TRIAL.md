# 仓储 Mac 本地试用版 · 0.5

这是Mac双击启动包，打开后通过Safari/Chrome使用现有WMS/OMS/PDA系统。包含Apple Silicon（M系列）和Intel两套离线依赖，要求macOS 11或更新版本。包内没有Python本体，电脑需先安装一次Python 3.12。当前没有Mac实机，不能声称已完成Mac实机验收；下列启动逻辑、离线依赖和包结构已在构建环境验证。

## 三步启动

1. 如果尚未安装Python 3.12，打开 https://www.python.org/downloads/macos/ ，找到Python 3.12.x版本，下载并安装“macOS 64-bit universal2 installer”。该安装器适用于M系列和Intel。已安装其他版本时可并存，无需卸载或修改系统Python。
2. 完整解压“仓储-Mac试用版-0.5.zip”，将整个“仓储Mac试用”文件夹放到个人“文稿”或“下载”等可写目录。不要直接在压缩包中运行，也不要只复制两个.command文件。
3. 双击“启动仓储.command”。首次会打开终端并在此文件夹的.venv中安装包内依赖；随后自动打开本地页面。管理员访问令牌会复制到剪贴板，在页面“访问令牌”框按Command+V，再点“连接工作空间”。令牌不会显示在终端、写入网址或保存在浏览器存储中。

首次安装依赖无需联网（安装Python本体可能需要联网）。如果默认8000端口被其他软件占用，会自动尝试8001–8010；以自动打开的地址和终端显示为准。页面只对本机开放。终端出现“请先安装Python 3.12”时先完成第1步，再重新双击。

若Mac提示无法验证或阻止打开这个下载文件，可右键“启动仓储.command”→“打开”，或在“系统设置→隐私与安全性”中为这一个文件选择“仍要打开”，以系统实际提示为准。如果是“没有执行权限”，也可以在“终端”输入`/bin/bash `（末尾有空格），把“启动仓储.command”拖进终端，再按回车。

## 停止、继续与切换岗位

- 使用期间保留启动的终端窗口；在该窗口按Control+C停止。下一次双击同一入口即可继续，数据不会自动清零。
- 重复双击不会再启动同一试用库，会提示使用原窗口。
- 需要换岗位时，先在网页退出，再双击“复制登录凭证.command”，输入1–5选择管理员、源仓作业员、目标仓收货员、初盘员A或复盘员B。回到网页Command+V登录。
- 令牌只由本机生成，有效30天。复制入口会检查账号是否有效，不会自动重发过期/撤销凭证；请勿分享accounts.token文件。
- 初始数据：示例货主、圣保罗/里约两仓、四库位、一个条码为789000000001的SKU、圣保罗仓已上架100件，以及TRIAL-ORDER-3待处理订单。只用于虚构流程试用。

## 数据在哪里

Mac入口使用以下独立目录：

`~/Library/Application Support/AtlasWMS/Trial-0.5/`

包含trial.sqlite3及accounts.token。Finder按Command+Shift+G，粘贴上方目录即可进入。复制凭证入口会把所选账号的令牌送到剪贴板，通常无需手动打开账号文件。POSIX目录/文件权限分别使用700/600保护。不要删除此目录来解决启动问题。

数据放在用户资料目录，换一份解压包不会覆盖试用数据；不要同时从两份解压包启动同一试用。若曾按通用源码包的命令在var/local-trial里试用，Mac入口不会擅自搬迁或覆盖那个库，而是在上述目录独立建立本轮示例。
